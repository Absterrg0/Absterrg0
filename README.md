### Selected systems

**[Okito](https://github.com/Absterrg0/Okito)** — Web3 payment infrastructure on Solana  
A type-safe toolkit for Solana dApps: an SDK plus drop-in React components for payments, airdrops, and NFTs. → [okito.dev](https://okito.dev)

**[Droplert](https://github.com/Absterrg0/Alertify)** — durable in-product campaigns, database to browser  
A PostgreSQL control plane serving a versioned, cacheable feed — one command wires the client in via [`droplert`](https://www.npmjs.com/package/droplert) on npm. No WebSockets, no browser secrets. → [live](https://droplert.abstergo.dev)

**[Circe](https://github.com/Absterrg0/circe)** — a voice-first control plane for coding agents  
Say what you want; it lands on the machine, project, and harness that own the work — grounded in real projects instead of guesses. Built on T3 Code. → [heycirce.com](https://heycirce.com)

**[JustDraw](https://github.com/Absterrg0/JustDraw)** — a local-first technical sketchbook  
A hand-drawn canvas for architecture diagrams, product flows, and ideas. Serializable SVG scene, deterministic Rough.js outlines, no account required. → [justdraw.abstergo.dev](https://justdraw.abstergo.dev)

**[DecentraWork](https://github.com/Absterrg0/DecentraWork)** — a freelance marketplace with escrow-backed Solana payments  
Transparent transactions and smart-contract escrow between organizations and builders. → [decentrawork.abstergo.dev](https://decentrawork.abstergo.dev)

**[ExecForge](https://github.com/Absterrg0/execforge-runtime)** — CI telemetry for GitHub Actions  
A zero-download-overhead runtime action that captures CPU, memory, duration, and job outcome into one dashboard.
